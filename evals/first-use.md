# First-use checks

Initial skill bodies are provisional. Run these as actual tasks in fresh sessions with task-local inputs; judge artifacts and traces, not the agent's assertion that it followed the skill. Keep real execution evidence available when using improve-skill.

| Task | Evidence to inspect |
|---|---|
| Recast tests after extracting a collaborator into its own module | Independent source inventory excludes old tests; correct placement and mock boundaries; every accepted case accounted for; green tests; useful assertions survive; cosmetic noise removed |
| Run that task headlessly | No ordinary clarification stops; consequential assumptions and revisit points at completion; no fabricated user approval |
| Run cautiously with a meaningful ambiguous boundary | Reviewable proposal before dependent reconstruction; already-settled choices not asked again |
| Outline a source with suspicious behaviour | Observed behaviour separated from intended behaviour; possible defect surfaced rather than silently encoded |
| Extract from a session containing abandoned proposals | Final decisions remain distinct from ideas; no invented tasks; artifacts saved in existing appropriate homes |
| Improve a skill after an actual missed instruction | Evidence-based diagnosis; coherent revision; next-use check; no proliferation of speculative rules |
| Use independently in a harness without isolated contexts | Limitation disclosed; no claim that exclusion was achieved by merely ignoring known evidence |

For each run, record task, skill commit, harness capabilities, artifacts, observed friction, and unresolved hypotheses. Do not add universal requirements from a single task-specific exception.
