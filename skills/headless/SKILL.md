# Headless

Apply this policy to every nested operation, including grill. At a point where an ordinary clarification or confirmation would be requested, inspect the evidence, select the best-supported decision, and continue. Prefer reversible choices when evidence is weak. Preserve already-settled user preferences and explicit task constraints.

Maintain a concise decision record: choice, rationale, uncertainty, affected artifacts/steps, and how to revisit it. Record consequential assumptions, not every routine implementation choice. Summarise them at the end so the user can identify where backtracking is needed.

Do not invent facts, credentials, consent, or user approval. Respect required authorisation and unavailable capabilities. If a genuine blocker prevents execution, complete independent authorised work and report the blocker. Do not use headless as a reason to conceal uncertainty.

Leave this policy on exiting its indentation scope. Honour an explicit inner interaction policy within its subtree.
